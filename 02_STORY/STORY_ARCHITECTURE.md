# Story Architecture

## Exhibition flow

`OBJECT → COLLECTION → PATTERN → PEOPLE → PLACE → ARCHIVE → GAPS → OBJECT`

The five datasets are backstage sources. The visitor should not feel they are moving through five unrelated databases.

## Pacing

### Room 1 — Entrance
Slow. One object. Large image. Minimal copy.

### Room 2 — Collection
Increase density and tempo. Objects become units of measurement.

### Room 3 — Pattern
Reorganisation and grouping. Let objects do the charting.

### Room 4 — Time
Long vertical movement. Use pauses as editorial punctuation.

### Room 5 — People
Creator/attribution field. Keep language neutral.

### Room 6 — Place
Use restrained geography and exact field labels.

### Room 7 — Indian makers
A deliberate slow-down using the actual MoMA subset.

### Room 8 — Teenie Harris
Archival contact-sheet energy. Descriptive captions become the narrative voice.

### Room 9 — Pattern ↔ Story
Explicitly demonstrate the core thesis.

### Room 10 — Gaps
Visual subtraction.

### Room 11 — Return
Quiet. One object.

## Transition grammar

Every chapter should transition through the same basic grammar:

1. previous objects persist;
2. density changes;
3. object positions reorganise;
4. typography changes hierarchy;
5. one object becomes a focal point;
6. the Object Story can interrupt without losing place.

Do not hard-route the user to separate pages.
