# Build Checklist

## Data

- [ ] Confirm all intended datasets are present.
- [ ] Add any remaining datasets to `raw/additional_datasets/`.
- [ ] Add the missing Met India dataset only if it is actually supplied.
- [ ] Run adapters.
- [ ] Validate row counts.
- [ ] Validate image and URL mappings.
- [ ] Regenerate source manifest.
- [ ] Regenerate findings.

## Narrative

- [ ] Read master dossier.
- [ ] Read narrative data map.
- [ ] Confirm every chapter has evidence.
- [ ] Confirm every number is calculated.
- [ ] Keep questions as questions.
- [ ] Preserve the five-dataset aggregate as a research corpus, not one museum collection.

## Interaction

- [ ] Scroll drives chapter states.
- [ ] Object field is virtualised.
- [ ] Hover is non-essential preview.
- [ ] Click/tap/keyboard opens Object Story.
- [ ] Escape closes.
- [ ] Focus returns to trigger.
- [ ] Scroll position restores.
- [ ] Related-object interactions preserve context.

## Object Story

- [ ] Conditional fields.
- [ ] No invented meaning.
- [ ] No invented provenance.
- [ ] Source link only when verified.
- [ ] No broken images.
- [ ] Alt text.
- [ ] Credit line where supplied.

## Motion

- [ ] Reduced motion.
- [ ] No layout thrashing.
- [ ] No thousands of simultaneous animation timelines.
- [ ] Object transitions remain understandable.

## Accessibility

- [ ] Keyboard navigation.
- [ ] Visible focus.
- [ ] Contrast testing.
- [ ] Touch targets.
- [ ] Text equivalents.
- [ ] No colour-only encoding.
- [ ] Mobile tested.

## Performance

- [ ] Virtualisation.
- [ ] Lazy images.
- [ ] Thumbnail-first loading.
- [ ] High-res only on selection.
- [ ] Measure initial load.
- [ ] Test low-power mobile hardware.

## Final validation

- [ ] No dashboard appearance.
- [ ] No broken source links.
- [ ] No guessed URLs.
- [ ] No unsupported cultural claims.
- [ ] No raw data modification.
