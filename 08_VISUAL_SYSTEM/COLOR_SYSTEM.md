# Color System

These are **working tokens**, not final accessibility-approved values. Final contrast testing must be performed against the actual artwork imagery and type sizes.

| Token | Working value | Use |
|---|---|---|
| `--oxblood` | `#4B1720` | primary dark accent |
| `--parchment` | `#F1E7D2` | main surface |
| `--ivory` | `#FBF7EE` | light surface |
| `--antique-gold` | `#A9854F` | restrained accent |
| `--ink` | `#211B18` | primary text |
| `--dusty-sage` | `#7E8A73` | secondary accent |
| `--blue-grey` | `#667785` | tertiary accent |

## Rules

- Do not use all tokens in every room.
- Artwork supplies most vivid colour.
- Maintain readable text contrast.
- Never encode a required distinction only through colour.
- Validate focus indicators separately.
