# Visual Direction

## Art direction

**EDITORIAL ART HISTORY × CONTEMPORARY INTERACTIVE ARCHIVE**

The site should resemble a digital exhibition wall that happens to be alive.

## Principles

1. Artwork imagery is the visual material.
2. Data appears as spatial behaviour, not dashboard chrome.
3. Typography is editorial and confident.
4. Metadata resembles museum labels.
5. Motion is slow when storytelling is intimate and faster when collection density rises.
6. Empty space is meaningful.
7. Every room can change atmosphere while retaining the same design grammar.

## Composition

- asymmetric editorial grids;
- overlapping image planes;
- contact sheets;
- large cropped details;
- floating labels;
- typographic numbers;
- object clusters;
- archival surfaces;
- generous negative space.

## Avoid

- KPI cards;
- generic dashboard panels;
- neon analytics aesthetics;
- excessive rounded cards;
- dense filter sidebars;
- decorative motion without narrative purpose;
- copying reference layouts.

## Room atmospheres

| Room | Atmosphere |

| Timeline | spatial chronology |
