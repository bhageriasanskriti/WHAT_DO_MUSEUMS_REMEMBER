# Motion System

## Motion should explain state

### 1. Reveal
Metadata enters progressively.

### 2. Accumulate
Objects multiply into a collection.

### 3. Reorganise
Objects move into categories.

### 4. Traverse
Objects travel through time/place.

### 5. Focus
One object enlarges while its context recedes.

### 6. Subtract
Missing fields create visible absences.

### 7. Collapse
The exhibition returns to one object.

## Micro-animation principles

- 150–300ms for interface affordances.
- 400–900ms for editorial transitions where appropriate.
- Longer sequences are driven by scroll progress rather than repeated timed animations.
- Prefer opacity/transform.
- Avoid animation that makes text unreadable.
- Reduced-motion mode preserves state changes without continuous movement.

These timings are starting tokens, not hard requirements.
