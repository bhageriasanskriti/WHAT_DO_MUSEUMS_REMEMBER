# Interaction Rules

| Input | Behaviour |
|---|---|
| Scroll | Advance narrative |
| Hover | Preview only |
| Focus | Same preview information as hover |
| Click | Inspect selected object |
| Tap | Inspect selected object |
| Enter / Space | Inspect focused object |
| Escape | Close Object Story |
| Close button | Close Object Story and restore scroll/focus |
| Keyboard tab | Move through actionable objects/controls |
| Touch swipe | Navigate simplified mobile sequences |

## Hard rules

1. No essential content is hover-only.
2. No interaction requires colour vision.
3. No object selection should cause a destructive navigation.
4. Object Story must preserve the user's narrative location.
5. All source links open the supplied specific record URL only.
6. Missing data is represented honestly.
7. Cross-dataset comparisons are labelled where taxonomies differ.
