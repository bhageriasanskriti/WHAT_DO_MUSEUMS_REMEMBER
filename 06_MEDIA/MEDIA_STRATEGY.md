# Media Strategy

## Source priority

1. Approved local image.
2. Supplied official/source image URL.
3. Designed no-image state.

## Local media

Place approved local assets in:
- `06_MEDIA/artwork-images/`
- `06_MEDIA/archival-images/`

Do not alter raw image URLs.

## Website loading

Use:
- thumbnail sizes for object fields;
- lazy loading;
- `loading="lazy"` where appropriate;
- responsive image sizing;
- high-resolution upgrade on Object Story selection;
- virtualisation for dense fields.

## No broken-image policy

Every image component needs:
- URL validation/fallback;
- neutral placeholder;
- alt text;
- no broken icon.

## Rights

An image URL being present does not mean the image is cleared for arbitrary reuse. Keep the museum credit line and source information visible in Object Story/source areas. Do not invent licenses.

## Visual references

Reference images belong in `06_MEDIA/references/` when supplied later. They should be analysed for principles, not copied.
